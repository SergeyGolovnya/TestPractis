## Цикл For...in
Используется для перебора свойств объектов.

## Цикл For...of
Используется для перебора итерируемых объектов (массивы, строки и т.д.).

## Цикл While
Используется, когда количество итераций неизвестно заранее.

## Цикл Do...While
Выполняет код хотя бы один раз, даже если условие ложно.

## Рекомендации по использованию
1. **For** - когда известно количество итераций
2. **For...in** - для перебора свойств объектов
3. **For...of** - для перебора элементов массивов и строк
4. **While** - когда условие может быть ложным с самого начала
5. **Do...While** - когда нужно выполнить код хотя бы один раз

## Особенности работы с вложенными массивами
1. Используйте очередь вместо рекурсии
2. Распаковывайте массив сразу при создании очереди
3. Добавляйте элементы в начало очереди при встрече вложенного массива
4. Проверяйте типы элементов перед обработкой
5. Следите за порядком обработки элементов

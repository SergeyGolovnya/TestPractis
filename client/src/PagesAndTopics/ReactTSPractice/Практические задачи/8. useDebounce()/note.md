// Методичка: useState(() => value) — зачем и как работает

В React useState можно инициализировать двумя способами:

1. useState(value)
   — Просто присваивает value как начальное значение состояния.

2. useState(() => value)
   — Передаёт функцию, которая возвращает начальное значение. Эта функция будет вызвана только один раз — при первом рендере (ленивая инициализация).

Зачем использовать функцию?
- Если начальное значение вычисляется сложно или долго, функция позволит выполнить вычисление только при первом рендере, а не при каждом рендере компонента.
- Это оптимизация для тяжёлых вычислений.

Пример:
// Плохо: expensiveCalculation() вызовется всегда
const [state, setState] = useState(expensiveCalculation());

// Хорошо: expensiveCalculation() вызовется только при первом рендере
const [state, setState] = useState(() => expensiveCalculation());

В случае с useDebounce:
const [debouncedValue, setDebouncedValue] = useState<T>(() => value)
// Здесь это не обязательно, но это хорошая привычка, если value может быть результатом вычислений.

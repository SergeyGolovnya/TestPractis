When array is used in React state, we need to deal with actions such as push and remove.

Implement useArray() to make life easier.

const {value, push, removeByIndex} = useArray([1, 2, 3])

Вот что нужно сделать по данной задаче:

1. **Реализовать хук useArray**  
   Нужно реализовать кастомный React-хук useArray, который:
   - Принимает на вход начальное значение массива (initialValue: T[])
   - Возвращает объект с:
     - value: текущее значение массива
     - push: функция для добавления элемента в массив
     - removeByIndex: функция для удаления элемента по индексу

2. **Требования к функциям:**
   - push(item: T): добавляет элемент в конец массива (аналогично Array.prototype.push, но с обновлением состояния)
   - removeByIndex(index: number): удаляет элемент по индексу (если индекс валиден)

3. **Типизация:**
   - Все функции и возвращаемые значения должны быть корректно типизированы через дженерики TypeScript.

4. **Корректная работа с состоянием:**
   - Использовать useState для хранения массива.
   - Не мутировать исходный массив напрямую, а создавать новый при каждом изменении (иммутабельность).

5. **Линтер:**
   - Убрать неиспользуемые переменные и импорты.
   - Все параметры должны использоваться.
   - Функция должна возвращать значение.

6. **Пример использования:**
   - В info.md приведён пример:  
     const {value, push, removeByIndex} = useArray([1, 2, 3])

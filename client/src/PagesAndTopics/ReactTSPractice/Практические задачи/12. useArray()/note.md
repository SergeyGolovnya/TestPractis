# Методичка: Работа с массивами и иммутабельностью в React

## 1. Почему нельзя мутировать state в React?
- React отслеживает изменения состояния по ссылке на объект/массив.
- Если мутировать (изменять напрямую) массив или объект, ссылка остаётся прежней, и React не "замечает" изменений.
- Это может привести к тому, что компонент не обновится.

**Пример неправильного подхода:**
```ts
value.push(item); // мутирует исходный массив!
setValue(value);   // React может не обновить компонент
```

**Пример правильного подхода:**
```ts
setValue(prev => [...prev, item]); // создаёт новый массив, React видит изменение
```

---

## 2. Как правильно добавлять элементы в массив в React state?
- Использовать spread-оператор или другие способы создания нового массива.
- Не мутировать исходный массив.

**Пример:**
```ts
setValue(prev => [...prev, item]);
```

---

## 3. Можно ли использовать промежуточную переменную?
- Да, если она создаёт новый массив, а не мутирует старый.

**Пример правильного подхода:**
```ts
setValue(prev => {
  const newArr = [...prev, item];
  return newArr;
});
```

**Пример неправильного подхода:**
```ts
setValue(prev => {
  prev.push(item); // мутирует исходный массив!
  return prev;
});
```

---

## 4. Почему важно менять именно ссылку?
- React сравнивает старое и новое значение state по ссылке (shallow compare).
- Если ссылка не изменилась — React считает, что ничего не поменялось.
- Если ссылка изменилась — React обновляет компонент.

---

## 5. Как правильно удалять элемент из массива по индексу?
- Использовать filter для создания нового массива без нужного элемента.

**Пример:**
```ts
setValue(prev => prev.filter((_, i) => i !== index));
```

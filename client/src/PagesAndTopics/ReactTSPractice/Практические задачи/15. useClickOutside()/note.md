# Подробное объяснение работы useClickOutside

```ts
import {useRef, useEffect} from 'react'

export function useClickOutside(callback: () => void) {
  const ref = useRef<HTMLDivElement>(null)
  useEffect(() => {
    const handleClick = (event: MouseEvent) => {
      if (ref.current && !ref.current.contains(event.target as Node)) {
        callback()
      }
    }
    document.addEventListener('click', handleClick)
    return () => document.removeEventListener('click', handleClick)
  }, [callback])
  return ref
}
```

---

## 1. Импорт хуков

- **useRef** — позволяет создать объект-ссылку, который будет храниться между рендерами.
- **useEffect** — позволяет выполнять побочные эффекты (например, подписки на события) и очищать их.

---

## 2. Объявление функции

- Это кастомный хук, который принимает функцию callback.
- **callback** — будет вызван, если пользователь кликнет вне отслеживаемого элемента.

---

## 3. Создание ref

- Создаём ref, который будет привязан к DOM-элементу (например, к div).
- ref.current изначально равен null, потом React сам присвоит ему DOM-элемент.

---

## 4. useEffect — подписка на событие

- **useEffect** запускается после каждого рендера, если изменился callback.
- Внутри useEffect:
  - Объявляется функция handleClick, которая будет вызываться при каждом клике по документу.
  - В handleClick:
    - Проверяем, что ref.current существует (то есть элемент уже в DOM).
    - Проверяем, что event.target (элемент, по которому кликнули) не находится внутри ref.current.
    - Если клик был вне отслеживаемого элемента — вызываем callback.
  - Подписываемся на событие click на всём документе.
  - Возвращаем функцию очистки, которая удаляет обработчик при размонтировании компонента или изменении callback.

---

## 5. Возврат ref

- Возвращаем ref, чтобы его можно было повесить на нужный элемент в компоненте.

---

## Итоговая схема работы

1. Ты вызываешь useClickOutside и передаёшь callback.
2. useClickOutside возвращает ref.
3. Ты вешаешь этот ref на нужный DOM-элемент.
4. useClickOutside подписывается на клики по документу.
5. Каждый раз при клике:
   - Если клик был вне элемента — вызывается callback.
   - Если внутри — ничего не происходит.
6. При размонтировании компонента или изменении callback — обработчик удаляется, чтобы не было утечек памяти.

---

## Для чего нужен каждый элемент

- **useRef** — хранит ссылку на DOM-элемент, чтобы можно было проверить, где произошёл клик.
- **useEffect** — подписывает и отписывает обработчик событий, чтобы всё работало корректно и не было утечек.
- **handleClick** — логика проверки, был ли клик вне элемента.
- **callback** — твоя функция, которая будет вызвана при клике вне элемента.
- **ref** — возвращается из хука, чтобы ты мог привязать его к любому DOM-элементу.
